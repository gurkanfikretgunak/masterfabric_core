# Changelog

## 1.0.0

- Initial release
- `masterfabric create` command generates full MasterFabric project scaffold
- MVVM + BLoC/Cubit architecture with base classes
- Pre-built views: Home, Profile, Settings
- GetIt + Injectable dependency injection setup
- GoRouter navigation with splash, onboarding, auth routes
- Theme system with dark mode toggle
- App configuration via `assets/app_config.json`
- Slang i18n setup with English translations
- Android permissions in AndroidManifest.xml
- iOS permission descriptions in Info.plist
- Cursor IDE integration: rules, agents, skills, AGENTS.md, MCP config
- Automatic `flutter pub get` and `build_runner` execution
